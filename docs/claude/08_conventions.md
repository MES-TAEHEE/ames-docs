- **DB 매개변수 형식·길이 = 개발 DB 컬럼**(09-30): **MasterDataRepository·SysRepository 의 공용 저장 헬퍼(`Exec`·`ExecCount`)는 매개변수마다 대상 컬럼을 적는다** — `("@Name", "테이블.컬럼", 값)`(10-12): `AMES.Data.Connection.ColumnParams` 가 형식·길이를 DB 컬럼 정보(INFORMATION_SCHEMA, 서버·DB 마다 처음 한 번 읽어 캐시)에서 정하고 저장 전에 값을 검사해 맞지 않으면 `DbValueException`(varchar·char = 컬럼 콜레이션 코드 페이지 바이트(10-29 — Latin1 은 CP1252 로 글자당 1바이트·한글 거부, Korean 은 CP949 한글 2바이트) · 그 코드 페이지에 없는 문자 거부 · nvarchar = 글자 수 · decimal = 컬럼 소수 자리로 반올림, 정수부 넘침 거부 · 정수 범위). 형식을 명시하면 SqlClient 가 긴 값을 조용히 자르므로 이 검사가 그것을 막는다. 문구는 Web `Program.cs` 가 `DbValueException.Formatter` 로 다국어(`Err.Db.*`)를 지정하고 화면은 `ex.Message` 를 그대로 보인다. 39개 메서드의 컬럼 표기는 SQL 을 해석해 만들었고, 정본 테스트는 `ColumnParamsTests`(규칙)·`TypedSaveRoundTripTests`(39개 메서드를 컬럼 최대 길이 값으로 왕복 — 한 트랜잭션 안에서 실행 후 되돌리며, 쓰기라서 `AMES_TEST_CONN` 을 지정했을 때만 돈다, 로컬 DB 권장). 새 저장 메서드도 이 헬퍼를 쓰면 컬럼만 적으면 된다. **`AddWithValue` 는 쓰지 않는다**(10-13 — 제품 코드 0곳): 조회 헬퍼(각 저장소의 `Query`, Api `ScalarString`·`QueryWithParam` 등)·SCM 공용 `Filter` 와 직접 조회는 `ColumnParams.AddFilter(cmd, "@X", "테이블.컬럼" | null, 값)` — 형식은 비교하는 컬럼에서 정하되 **검사·절단을 하지 않는다**(길이 = 컬럼과 값 중 긴 쪽이라 너무 긴 값은 잘려 엉뚱한 행과 맞지 않고 그대로 "없음", CP949 에 없는 문자가 든 값은 nvarchar 로, `date` 컬럼은 자정 값만 date·나머지 DateTime 은 datetime2(7), 값 형식이 컬럼과 다르면 값 형식). 컬럼이 없는 값(TOP·DATEADD 인자, 여러 컬럼을 잇는 검색어, CTE·파생 표 컬럼, `SIS_TEST` 옛 WMS 표)은 `null` 로 값 형식(문자열 nvarchar). 저장(INSERT 값·UPDATE SET)은 `ColumnParams.Add`(SCM 공용 `Add` 도 같음), 저장 프로시저 매개변수는 `"프로시저.@매개변수"`(INFORMATION_SCHEMA.PARAMETERS — 입고 처리처럼 쓰는 프로시저는 `Add`, 조회 프로시저는 `AddFilter`). `LEFT(@x, n)` 처럼 SQL 이 일부러 잘라 저장하는 값은 저장 검사에 묶지 않는다. 태그가 DB 에 실제로 있는지는 `ColumnTagsTests`(소스 전체의 태그를 개발 DB 와 대조), 규칙은 `ColumnParamsTests` 가 정본. `cmd.Parameters.Add("@X", SqlDbType.T, N)` 의 T·N 은 비교·대입되는 개발 DB 컬럼과 같게 둔다 — varchar 컬럼에 `NVarChar`(암시적 변환), nvarchar 컬럼에 `VarChar`(한글 손실), 컬럼보다 짧은 N(저장 시 조용히 잘림)을 쓰지 말 것. 한 매개변수가 여러 컬럼에 쓰이면 가장 짧은 컬럼 길이, LIKE 검색 매개변수는 `%` 를 붙이므로 길어도 된다. 읽기도 컬럼 형 그대로 — `smallint` 를 `as int?`, `bigint` 를 `as int?`, `int` 를 `as string` 으로 읽으면 **예외 없이 null** 이 된다(09-30 `PP_LineSchedule.StartMin/EndMin`·`MD_Mold.CumulativeShots`·`PP_LineDowntimeLog.AndonID` 수정). 화면 입력칸 `MaxLength` 도 컬럼 길이와 같게.
