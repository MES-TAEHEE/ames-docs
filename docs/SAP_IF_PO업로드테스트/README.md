# PP-002 수주(PO) 업로드 테스트 파일

PP-002 「엑셀 업로드」용 파일 8개. 열 머리글 **이름**으로 열을 찾으므로(영문 이름, 대소문자·공백 무시) 필요한 7개 열만 둔다.
나머지(Vendor Name·PART NAME·Unit 등 SRM 원본의 다른 열)는 업로드에 쓰이지 않거나 처리 중에 자동으로 채워진다.

| 열 | 구분 | 용도 |
|---|---|---|
| `P/O No.` | **필수** | 수주 번호 `9100000001-10`(마지막 `-숫자` = 라인 번호) |
| `PART NO` | **필수** | 품번 |
| `ArrReq. Date` | **필수** | 납기일 |
| `P/O Qty` | **필수** | 수주 수량(음수 행은 가져오지 않음) |
| `Order Date` | 저장 | 발주일 |
| `Deliv. Qty` | 저장 | 납품 수량(없으면 0) |
| `Vendor Code` | 대조 | 고객 SRM 설정의 VENDCD 와 비교(일치·불일치 안내) |

업로드 창에서 **고객사는 `CUS-SAV`**(Savannah, VENDCD 310471)를 고르면 업체 코드가 「일치」로 나온다.
발주번호는 `9100000001-nn`(시험용 — 운영 SRM 번호 `41…` 와 겹치지 않는다), 발주일 2026-11-20.

| 파일 | 기대 결과 |
|---|---|
| `PO_정상_10건.xlsx` | 읽기 성공 — 10행(품번 4종 합계 140개). 업로드·저장 후 PP-002 에서 확정 → PP-003 WO 생성 가능 |
| `에러1_발주량_숫자아님.xlsx` | 차단 — `MM31006 2행 '발주량' 값 'ABC' 을 숫자로 읽을 수 없습니다.` |
| `에러2_품번_20자초과.xlsx` | 차단 — 품번·발주번호 20자 초과 안내 |
| `에러3_필수열없음(ArrReq. Date).xlsx` | 차단 — `MM31006 필수 열이 없습니다: 납기일자` |
| `에러4_유효행없음(P_O No. 없음).xlsx` | 차단 — `MM31006 구매오더 리스트에 유효한 P/O 행이 없습니다.` |
| `에러5_음수수량만.xlsx` | 차단 — 음수 수량(반품) 행만 있어 가져올 것이 없음 |
| `경고1_마스터에없는품번.xlsx` | 읽기 성공 + 「마스터에 없는 품번」 경고(`ZZ-TEST-0001`·`ZZ-TEST-0002`) |
| `경고2_업체코드불일치.xlsx` | 읽기 성공 + 업체 코드 불일치 경고(파일 999999 ↔ 고객 설정 310471) |

품번(`F2321-NV000NNB`·`F2321-NV000PNY`·`M0211-DW011WK`·`M0221-DW011WK`)은 SAP 에서 받은 완제품이라 AMES `MD_Item` 에 있다.
단 **라우팅(`RoutingType`)·적입수량·BOP·금형·라인 배정이 비어 있어** PP-003 에서 WO 를 만들면 거부될 수 있다(수주 업로드·확정까지는 문제없다).

## 11-23 정리 — B1 에 있고 WO 까지 만들어지는 완제품 4종

시험 PO(`PO_정상_10건.xlsx`, 10행·합계 140개 — 수량 10·20개)는 B1(EOS_IF `IF_MD_ITEM`)에 실제 있는 완제품 **F2321-NV000NNB·F2321-NV000PNY·M0211-DW011WK·M0221-DW011WK** 만 쓴다.
B1 에 없는 AMES 전용 품번 파일은 삭제했다. 운영 AMES 에 아래를 등록했다(PP-003 규칙 — 코어·LOT PREFIX·라인·금형 — 읽기 전용 점검으로 4종 모두 막힘 없음 확인).

| 등록 | 내용 |
|---|---|
| RoutingType | 완제품 4종 모두 `A`(사출 → 이미징). SAP 는 `U_RoutingType` 을 아직 안 보냄 |
| BOP(공정 20 IMG) | 완제품 4종 · 90초 · `ST-IMG-05` (같은 계열 품번 값을 참고한 임시값) |
| 임시 금형 `TMP-0001` | 코어 `82321-DW010`(M0221 의 RH 코어)에 금형이 없어 만든 임시 데이터 — `LINE-INJ-06`·UPH 120. 금형·BOP 도 SAP 가 보내지 않는 AMES 마스터. 실제 금형이 정해지면 MD 화면에서 교체·삭제 |
| BOP(공정 10 INJ) | `82321-DW010` · 60초 · `ST-INJ-06` (같은 계열 코어와 동일) |

- 등록 계정은 `SAP-TEST`·`TMP`(MD 화면에서 구분 가능). 금형 정보는 SAP 인터페이스 정의서(V1.2)에 없다 — 금형·BOP·라우팅 단계는 전부 AMES 가 직접 가진다.
- **주의**: SAP 가 완제품을 RoutingType 비운 채 다시 보내면 SAP 우선 규칙으로 RoutingType 이 지워질 수 있다(BOP·금형은 SAP 가 보내지 않아 유지).
