2. 테스트 시나리오

그룹 → 시나리오 순서로 접고 펼쳐 본다. 결과 칸은 모의 테스트 중 직접 고르며 브라우저에 저장된다.
작성 기준: 현행 시스템 기능 명세. 항목 번호는 화면 ID(예 PP-002, INJ-MAIN)와 맞춘다. 통합 흐름(E2E)은 앞 단계의 결과가 다음 단계의 입력이 되도록 이어져 있으며, 중간 단계가 실패하면 그 뒤 E2E 는 보류로 두고 실패 건부터 다시 실행한다.
